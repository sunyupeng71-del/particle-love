# 粒子情书 · Particle Love

一个用原生 Canvas 制作的粒子动画情书页面，献给范晓语。

## 效果预览

- 粒子在深蓝紫渐变背景上排列成爱心形状
- 粒子之间用半透明细线连接
- 鼠标划过时，附近粒子被推开，移开后自动聚合回爱心
- 点击页面触发烟花爆炸，1.5 秒后粒子缓慢归位
- 爱心下方「For 范晓语」文字持续呼吸灯效果

## 技术栈

- 纯 HTML5 Canvas，无任何第三方库
- 物理模拟：弹簧回归力 + 速度阻尼 + 鼠标斥力
- 心形由参数方程生成：`x = 16sin³(t)`，`y = 13cos(t) - 5cos(2t) - 2cos(3t) - cos(4t)`
- 响应式设计，窗口缩放自动适配

## 使用方式

直接用浏览器打开 `index.html`，无需构建工具。
