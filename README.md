# Particle Love · Fable Edition

> 一个写给一个人的网页。
> 与其说是一件作品，不如说是一封会呼吸的情书。

献给范晓语。

## 关于

这不是一个会主动讨好谁的页面。它更像一片安静的星野——会呼吸，会记得来过的人，会在被触碰时，用极克制的方式回应。

它的脾气只有四句：说得极少，记得极多，从不先开口，从不让人愧疚。

## 体验

打开时，先是一片黑。然后偏左下亮起一颗星——在被触碰之前，整个宇宙都是哑的。星群随之像墨滴入水般渗开，一个名字浮现，又碎成星尘。

此后，它只是存在着：

- 整片星空以一次呼吸的节奏明灭；久无人来便渐渐睡去，再被唤醒。
- 它按打开的**时辰**换上不同的夜色，深夜会有一颗守夜的星；她生日那天，会有一弯一年只出现一次的月。
- 它**记得**她——停留的痕迹、连过的星座，都淡淡地留在天上；那颗认生的星，每次都比上次靠近一点。
- 轻点，是向天空提问：有时是一朵静静绽放又如雪落下的光，有时是一道远年的流星，有时只是沉默。

而这一切的尽头，是一场被拆成一百次打开的日出——每来一次，天就亮一点点，小到无法察觉。直到第一百次，天亮。

它一生只说七句话，每句只说一次。其中没有一个「我」字，也没有一个「爱」字。

## 技术

- 纯原生 **HTML5 Canvas**，无框架、无构建工具。
- 物理：弹簧回归 + 阻尼 + 鼠标场；三层景深星野 + 柔光。
- 记忆：**localStorage**——到访次数、停留痕迹、连成的星座、黎明进度，跨会话留存。
- 声音：**Tone.js**（五声音阶钢琴、终曲和弦）+ 原生 **Web Audio**（低频环境音、交互轻响），全部实时合成。无任何音频文件，无循环背景乐。
- 文字：系统原生字体，零外部加载。

## 打开

用浏览器打开 `index.html` 即可；托管成一个链接会更稳（Tone.js 从 CDN 加载，需联网）。

声音会在**第一次触碰**时苏醒——所以，动一动鼠标。
